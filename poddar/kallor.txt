# Poddar och nyhetskällor för Världspodden

# En källa per rad. Tre sätt att ange en källa:
#   1. Länk till ett RSS-flöde, t.ex.  https://exempel.se/podd.xml
#   2. Länk från Apple Podcasts, t.ex. https://podcasts.apple.com/se/podcast/namn/id123456789
#      (i Podcasts-appen: tryck på podden → dela → Kopiera länk)
#   3. sök: och poddens namn, t.ex.     sök: Ekot
#      (tar första träffen i Apples poddkatalog)
#
# Rader som börjar med # hoppas över. Ändringar slår igenom vid nästa hämtning
# (inom en halvtimme, eller direkt efter att filen sparats).
